Parameters

allowedTypes Func<Type, bool>

A delegate that determines what types are allowed to be serialized and deserialized.

Remarks

The delegate is called with the full type, including constructed generic types and array types. It is the delegate's responsibility to inspect generic arguments and array element types; a delegate that only looks at the type itself (for example at its assembly or namespace) will allow types such as Allowed.Wrapper<NotAllowed.Anything>.

public ObjectSerializerAllowedTypesConvention(params Assembly[] allowedAssemblies)

Parameters

allowedAssemblies Assembly[]

A collection of allowed assemblies whose types can be serialized and deserialized.

Remarks

A type is allowed when it is declared in an allowed assembly or, if AllowDefaultFrameworkTypes is true, is a default framework type. Constructed generic types and array types are only allowed when their generic arguments and element types are themselves allowed, so a generic type declared in an allowed assembly cannot be used to smuggle in a type from an assembly that is not allowed. When AllowDefaultFrameworkTypes is true the default framework generic types (for example List<T> and Dictionary<TKey, TValue>) can be constructed over allowed types, such as List<AllowedAssembly.MyType>.
